# EvilTwin-Esp32
***Equipe: Saulo Rafael, Luiz Filipe***

O projeto EvilTwin-Esp32 consiste no desenvolvimento de um dispositivo embarcado de IoT baseado no ESP32 cuja proposta é simular um ataque do tipo Evil Twin, no qual o ESP32 cria um ponto de acesso falso com características semelhantes às de uma rede legítima, ao mesmo tempo em que executa um ataque de desautenticação forçada contra o AP original. Dessa forma, os dispositivos que estiverem conectados à rede verdadeira são induzidos a perder a conexão e, consequentemente, tendem a se reconectar ao ponto de acesso falso criado pelo ESP32. Em vez de atuar por interferência física de radiofrequência, o sistema utiliza a injeção de quadros de gerenciamento forjados para provocar a negação de serviço local no AP legítimo e redirecionar a conexão para o AP controlado pelo projeto. Além disso o EvilTwin-Esp32 também realiza a captura de tráfego e de informações de conexão no ambiente controlado, funcionando como um sniffer em modo promíscuo. Como o dispositivo não possui interface física dedicada, o projeto implementa um servidor web embutido no próprio ESP32, acessível pelo navegador, que permite visualizar os dados capturados, acompanhar os logs e aplicar filtros de busca semelhantes ao funcionamento do comando “localizar” do navegador.
